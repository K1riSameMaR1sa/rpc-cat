脚本没有加载

页面里的 JavaScript 没有执行，所以所有按钮都不会有反应。

最常见的原因：直接双击打开了本文件。 浏览器的安全策略禁止 file:// 下的 ES 模块， 脚本会被直接拦掉。

三种解决办法，任选其一：

  1. 打开同目录下的 rpc-cat.html（单文件版， 双击即可用，功能完全一致）；
  2. 在本目录起一个本地服务器： npm run serve 或 python -m http.server 8080， 然后访问 http://localhost:8080/；
  3. 部署到 GitHub Pages 后访问线上地址。

若你是通过 http:// 打开的还看到这条提示， 请按 F12 打开控制台，把红色的报错信息发出来。
